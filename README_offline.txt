WIE NUTZE ICH DIE OFFLINE-VERSION?
------------------------------------------------------------------------

1. Exportieren Sie dieses Projekt als ZIP-Datei (über das Einstellungen-Zahnrad
   oben rechts in der AI Studio Oberfläche).
2. Entpacken Sie die ZIP-Datei auf Ihrem Computer (z.B. auf dem Desktop oder
   auf einem USB-Stick).
3. Suchen Sie im Hauptordner die Datei:
   
   =>  MiD-PCT_Dashboard_OFFLINE.html

4. Machen Sie einfach einen DOPPELKLICK auf diese Datei. Sie öffnet sich
   sofort in Ihrem bevorzugten Webbrowser (Chrome, Firefox, Safari, Edge usw.).

------------------------------------------------------------------------
EIGENSCHAFTEN & VORTEILE DIESER VERSION:
------------------------------------------------------------------------

* VOLLSTÄNDIG AUTARK: Die gesamte Logik (React, Recharts-Diagramme, Styling)
  ist direkt in dieser einen HTML-Datei eingebettet. Sie benötigen keine
  externen Stylesheets oder JavaScript-Dateien.
* OFFLINE-FÄHIG: Sie können das Dashboard mitten im Wald ohne Internet-
  Verbindung öffnen und uneingeschränkt nutzen!
* DATENSCHUTZ & SPEICHERUNG: Alle Daten (Budgets, Personalkosten, Rechnungen,
  Mittelabrufe, verknüpfte Meilensteine und Aufgaben) werden sicher und lokal
  direkt in Ihrem Webbrowser (über "localStorage") gespeichert. Es werden
  keine Daten an Server übertragen.
* KOPIERBAR & SCHNELL: Sie können diese eine Datei per E-Mail an Kollegen
  versenden oder auf einen USB-Stick ziehen. Sie läuft überall sofort.
